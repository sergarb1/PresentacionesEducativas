# Spec: Sistema de Diseño

## Descripción
Sistema visual compartido para todas las presentaciones.

## Paleta de colores

### Fondos
- `--bg-primary: #0B0F14` — fondo principal
- `--bg-secondary: #111827` — fondo secundario
- `--bg-tertiary: #1a2332` — fondo terciario
- `--bg-card: #1e293b` — fondo de tarjetas
- `--bg-code: #0d1117` — fondo de código

### Texto
- `--text-primary: #f1f5f9` — texto principal
- `--text-secondary: #94a3b8` — texto secundario
- `--text-muted: #64748b` — texto apagado

### Acentos
- `--accent-cyan: #06b6d4` — información
- `--accent-green: #10b981` — éxito
- `--accent-magenta: #ec4899` — énfasis
- `--accent-violet: #8b5cf6` — secundario
- `--accent-red: #ef4444` — error
- `--accent-yellow: #f59e0b` — advertencia
- `--accent-blue: #3b82f6` — enlace

## Tipografía
- Inter / Roboto para texto
- JetBrains Mono / Fira Code para código
- Títulos: bold, 2.5rem h1, 1.8rem h2, 1.35rem h3

## Layouts Slidev
- `cover` — portada con inicio.png
- `end` — cierre con final.png
- `section` — separador de sección
- `two-cols` — dos columnas
- `center` — contenido centrado
- `code` — código fullscreen

## Archivos
- `styles/variables.css` — tokens de diseño
- `styles/typography.css` — tipografía
- `styles/components.css` — estilos de componentes
- `styles/layout.css` — layouts de diapositiva
